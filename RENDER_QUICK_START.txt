  ⚠️ COMMON ISSUES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "Using Python version 3.14.3"
   → PYTHON_VERSION variable not set!
   → Go to Environment tab
   → Add: PYTHON_VERSION = 3.11.9
   → Manual Deploy → "Clear build cache & deploy"

❌ "pydantic-core compilation failed"
   → This means Python 3.14 is being used
   → See fix above

❌ "Application failed to respond"
   → Check Logs tab for errors
   → Verify all environment variables are set
   → Check SUPABASE_URL and SECRET_KEY

❌ "CORS policy error"
   → Update CORS_ORIGINS with your frontend URL
   → Format: https://your-frontend.vercel.app
